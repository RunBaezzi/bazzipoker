# 기억포커 MEMORY POKER

16장의 카드를 15초 동안 외운 뒤, 공유 카드 3장과 조합할 2장을 골라 족보로 겨루는 게임.

- 솔로 모드: 5라운드 점수제, 등급(S~D), 최고 기록 저장
- 온라인 1:1 대결: 4자리 방 코드로 친구와 5라운드 승부
- 카드 4열 배치, 족보표 열기/닫기
- 사운드: 라운지 재즈 배경음악(원곡, 약 82초 반복)과 재즈 팡파르·선택 완료음, 카드 뒤집기·선택 효과음 (오른쪽 위 🎵/🔊 버튼으로 켜고 끄기)
- 악기 음원: MusyngKite 사운드폰트 (CC BY-SA 3.0, gleitz/midi-js-soundfonts 배포본) — 출처 표기 필요

## GitHub Pages에 올리는 법 (코드 몰라도 됨)

1. github.com 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name에 `memory-poker` 입력 → **Public** 선택 → **Create repository**
3. 생성된 화면에서 **uploading an existing file** 클릭
4. `index.html`, `README.md` 두 파일을 끌어다 놓기 → 아래 **Commit changes** 클릭
5. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
6. Branch를 **main** / **/(root)** 로 고르고 **Save**
7. 1~3분 뒤 `https://<내 아이디>.github.io/memory-poker/` 주소로 접속

수정할 때는 저장소에서 `index.html`을 다시 업로드(같은 이름으로 덮어쓰기)하면 1~3분 뒤 반영됩니다.

## 온라인 대결 방법

1. 한 명이 **온라인 1:1 대결 → 방 만들기** → 4자리 코드 확인
2. 다른 한 명이 같은 주소로 들어와 코드 입력 → **참가**
3. 들어오는 즉시 게임 시작

연결은 PeerJS(브라우저끼리 직접 연결)를 사용하므로 별도 서버가 필요 없습니다.

## 알려진 한계

- 일부 회사·학교 와이파이에서는 직접 연결이 막혀 접속이 안 될 수 있습니다. 이때는 휴대폰 데이터(LTE/5G)로 바꿔보세요.
- 방을 만든 사람이 페이지를 닫으면 방이 사라집니다.
- 친구끼리 즐기는 용도입니다 (개조한 클라이언트의 부정행위는 막지 못함).
